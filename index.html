Notes

          
    
            
  • Batch output is a ZIP with a timestamped folder (YYYY-MM-DD_HHMMSS) inside.
    • 
            
  • 
              Output names drop any existing _SILO, _SILO-2200x2200 or
              _DIM before adding their own, so Fern_SILO.png →
              Fern_DIM.jpg.
            
    • 
            
  • CSV rows are matched to images by file name, with or without the extension or suffix.
    • 
            
  • Images missing from the CSV are skipped for DIM. Silo/Web (under Legacy Options) don't need the CSV.
    • 
            
  • Left-to-right, the pot is centered so lopsided leaves don't shift it. Top-to-bottom, the whole plant is centered with equal space above and below. Empty margins in the input image are ignored.
    • 
            
  • Transparency is used to find the plant. Images with no transparency fall back to treating near-white as background.
