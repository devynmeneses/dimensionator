Notes 📝

  • Batch output is a ZIP containing a timestamped folder (YYYY-MM-DD_HHMMSS).

  • Filename rule strips _SILO or _SILO-2200x2200 before appending _DIM.jpg.

  • Alpha-based bounds are used first. White-threshold fallback is used only if image has no transparency.

  • Sometimes when you select a folder, it'll say there's one more file selected than what's actually in there. This is completely fine and is just a browser dependent bug.
